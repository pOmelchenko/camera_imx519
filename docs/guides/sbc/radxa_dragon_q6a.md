# IMX519 на CAM3/J7 Radxa Dragon Q6A

## Одиночные RAW10 на CAM3 при 100 кГц

На Dragon Q6A с ядром `7.0.11-7-qcom` и модулем `q6a-cam3.1` прошли три
серии по три запуска полного кадра. При 400 кГц удалось 0/3 в первоначальной
серии и 2/3 в контрольной. В неудачных попытках драйвер сообщал об ошибке
записи общей таблицы регистров. [Настройки, серии и измерения RAW10](../../../target/sbc/radxa_dragon_q6a/validation/cam3-2026-11-22.json).

После [установки комплекта](../../../target/sbc/radxa_dragon_q6a/README.md)
и перезагрузки на стенде используйте:

```sh
(
set -eu
cd ~/q6a-imx519
cat /sys/module/imx519/version
od -An -tu4 --endian=big /sys/bus/i2c/devices/20-001a/of_node/../clock-frequency
sensor=$(media-ctl -d /dev/media0 -e 'imx519 20-001a')
v4l2-ctl -d "$sensor" --set-ctrl=exposure=1000,analogue_gain=768,digital_gain=256
for n in 1 2 3; do
    python3 capture.py --port cam3 --size 4656x3496
done
)
```

Ожидаемая частота в загруженном DT — `100000` Гц. На этом стенде каждый
успешный запуск дал 20 360 704 байта `pRAA` при шаге строки 5824 байта.

Для неподвижной сцены в испытанном помещении выдержка 3000 строк вместо 1000
увеличила сигнал в центре в 3,04 раза при тех же усилениях. По белому листу
при этом освещении получены множители R ×1,39, G ×1,00 и B ×2,21 после
вычитания принятого уровня чёрного 64 из RAW10. Для просмотра статичного
кадра применялось +2 EV перед кодированием sRGB. Баланс белого следует
измерять под освещение, а выдержку для движущегося сканера подбирать по смазу.

## Контрастный Auto на штатном CAMSS

На Q6A с Ubuntu 24.04.5 LTS, ядром `7.0.11-7-qcom`, модулем
`q6a-cam3.1` и CAM3 на 100 кГц отдельная сборка libcamera навелась на
неподвижные мишени примерно в 100, 200 и 300 мм. При одинаковых настройках
полноразмерного RAW10 сравнили три кадра на позиции Auto и три на лучшей
из измеренных ручных позиций. Диапазоны оценки резкости перекрылись во
всех трёх случаях. [Версии, позиции объектива и измерения](../../../target/sbc/radxa_dragon_q6a/validation/cdaf-2026-11-23.json).

Рецепт использует [закреплённый исходник Radxa](https://github.com/radxa-pkg/libcamera/tree/de1e9bc095e23085e77533357d2582176de0a582)
и [патчи для IMX519 и Simple IPA](../../../target/sbc/radxa_dragon_q6a/libcamera/).
На штатном CAMSS маршрут фазовых данных недоступен. Патч отката
выключает только что включённую связь при неудачной настройке фазового
захвата, после чего запускаются RGB и контрастный поиск.

Соберите runtime на машине с Docker, способным запускать ARM64-контейнеры,
из корня репозитория:

```sh
bash target/sbc/radxa_dragon_q6a/libcamera/build-runtime.sh
```

В каталоге, напечатанном в строке `Runtime:`, остаются `runtime.tar.gz`,
`runtime.sha256` и результаты тестов IPA. Перенесите архив и его checksum
на Q6A. В каталоге с этими файлами проверьте архив и распакуйте его в
новый пользовательский каталог:

```sh
sha256sum -c runtime.sha256
runtime=$(mktemp -d "$HOME/imx519-cdaf.XXXXXXXX")
tar -xzf runtime.tar.gz -C "$runtime"
bash "$runtime/run.sh" -l
```

Wrapper подключает библиотеки и профиль `imx519.yaml` из архива для
текущего процесса. Запуск использует системный CAMSS и не требует sudo.

На свободной камере направьте объектив на одну освещённую контрастную
мишень. Сохраните топологию перед и после прогона:

```sh
media-ctl -d /dev/media0 -p > media-before.txt
camera=/base/soc@0/cci@ac4b000/i2c-bus@1/imx519@1a
bash "$runtime/run.sh" -c "$camera" \
    --stream role=viewfinder,width=1920,height=1080,pixelformat=XRGB8888 \
    --capture=330 --script="$runtime/af-once.yaml" \
    --metadata > auto.log 2>&1
media-ctl -d /dev/media0 -p > media-after.txt
grep 'Contrast AF position' auto.log
```

На испытанном стенде получено 330 кадров подряд, в логе появилась запись
`Contrast AF position … state 2`. `AfState = 2` соответствует `Focused`.
Для сохранения изображения добавьте `--file="$PWD/auto.ppm"`. В прогоне
с записью кадра зафиксировано 63 пропущенных номера при 330 полученных
кадрах. Для измерения частоты используйте запуск с одними метаданными.

После остановки libcamera в графе
могут остаться активные связи её маршрута IMX519. На свободном устройстве
сверьте графы и восстановите только добавленные этим запуском связи
CSIPHY→CSID и CSID→VFE. Для возврата к системному libcamera запускайте штатный
`cam` без wrapper.

При трёх мишенях в одном кадре Auto выбрал корону на 300 мм. Применимость
этой проверки ограничена однократным контрастным AF. Выбор зоны через
`AfMetering`/`AfWindows`, Continuous и фазовый AF требуют отдельной проверки.

## Поток в эксперименте при 400 кГц

11 октября 2026 г. на Q6A с Ubuntu 24.04.5 LTS и ядром `7.0.11-7-qcom`
проверен цветной поток имеющегося 80° модуля IMX519 на CAM3/J7.
Ревизия платы камеры и распиновка установленного шлейфа не зафиксированы.
[Оригинальный протокол, версии ПО и SHA-256 снимка](../../../target/sbc/radxa_dragon_q6a/validation/cam3-2026-10-11.json).

### Проверенная конфигурация потока

Опыт выполнен с [драйвером, оверлеями и демо ревизии 93c6e57](https://github.com/pOmelchenko/camera_imx519/tree/93c6e57ca556b0f96ca250a1414a4347fc280b2b/target/sbc/radxa_dragon_q6a).
Источник регистрировался при загрузке со строгой проверкой ID `0x0519`.
AR0234 на CAM2 была включена в конфигурацию загрузки. Одновременный захват
с двух камер в этот опыт не входил.

| Параметр | Наблюдение |
| --- | --- |
| Сенсор и объектив | CCI1/I²C1, адреса `0x1a` и `0x0c`, GPIO78, CSIPHY3, две линии |
| Запуск | При 1 МГц были тайм-ауты записи регистра `0x0100`. Поток запустился при I²C 400 кГц, задержке питания 100 мс и исправлениях runtime PM |
| Вход ISP | 2328 × 1748, RGGB RAW10 CSI2P, 2912 байт на строку |
| Выход демо | 1920 × 1080, XBGR8888/sRGB, 7680 байт на строку |
| Ограниченный прогон | 600 кадров, 29,9002 кадр/с по меткам времени, ноль пропусков просмотра и ошибок захвата |
| Продолженный просмотр | 6696 отображённых кадров, 100 устаревших кадров пропущено при выводе, ноль ошибок захвата |

### Как повторить ограниченный прогон

На плате с указанной ревизией экспериментального комплекта проверить `cam -l`
и `media-ctl -p`. Записанный ID камеры —
`/base/soc@0/cci@ac4b000/i2c-bus@1/imx519@1a`. Из каталога
`target/sbc/radxa_dragon_q6a` **экспериментальной ревизии**, в графической сессии
со свободной камерой, выполнить

```sh
make demo
capture_dir=$(mktemp -d)
sh tools/preview.sh --compare --frames=600 --snapshot="$capture_dir/comparison.ppm"
```

В снимке слева кадр ISP, справа результат шумоподавления. Сцена была видна,
но тёмная и нерезкая. AK7375 предоставил `focus_absolute` 0–4095.
Движение объектива, AF, холодный старт и физический захват на CAM1/CAM2
этой записью не проверялись. Для испытаний текущего установщика и прямого RAW10
используйте [действующий комплект](../../../target/sbc/radxa_dragon_q6a/README.md).
