# Просмотр IMX519 с шумоподавлением

Демка перенесена из `camera_ar0234` и собрана на Q6A. Проверка фильтра
на GPU пройдена; живой поток IMX519 пока не проверен, её оверлей отключён.

Из терминала рабочего стола Q6A, в каталоге этой платформы:

```sh
make demo
sh tools/preview.sh --list-cameras
sh tools/preview.sh
```

По умолчанию выбирается единственная IMX519 и запрашивается RGBX
1920×1080. Фактические размер и stride определяет libcamera, демка
учитывает выравнивание строк. При нескольких IMX519 выбрать точный ID:

```sh
sh tools/preview.sh --camera='/base/soc@0/cci@ac4b000/i2c-bus@1/imx519@1a'
```

Этот ID — ожидаемый маршрут CAM3, его нужно сверить с `--list-cameras`.
AR0234 и другие сенсоры просмотр не выбирает. Одновременно отображается
одна камера.

| Клавиша | Действие |
| --- | --- |
| N | Включить/выключить фильтр |
| C | Сравнение: слева исходник, справа обработанный кадр |
| 1 / 2 / 3 | Лёгкий / средний / сильный фильтр |
| F | Полный экран |
| Esc / Q | Закрыть окно и освободить камеру |

Фильтр OpenGL ES 3 корректирует изолированные яркие выбросы и уменьшает
пространственный/временной шум после дебайеризации. В тенях обработка
сильнее; история хранится в RGBA16F. При движении накопление уменьшается.
В заголовке окна показаны режим и частота. Просмотр выбирает свежий кадр
при отставании и отдельно считает пропуски и ошибки захвата.

Проверка шейдера без камеры, в графической сессии:

```sh
make check
```

На GPU Q6A `FD643` / Mesa 25.2.8 лёгкий фильтр дал RMS шума 0,596
от исходного для синтетической неподвижной сцены. В тесте теней режимы
1/2/3 дали 0,163/0,115/0,113 при сохранении 94/93/92% контраста тусклой
тонкой линии. Это тесты алгоритма; качество и частота на IMX519
ещё не измерены. [Запись проверки](../validation/2026-10-11.json).

После включения камеры ограниченный прогон со снимком сравнения:

```sh
capture_dir=$(mktemp -d "$HOME/imx519-demo.XXXXXX")
sh tools/preview.sh --compare --frames=600 --snapshot="$capture_dir/comparison.ppm"
```

PPM сохраняет исходник слева и результат справа.
`--width=1280 --height=720` задаёт другой запрашиваемый размер;
`--help` показывает все параметры. Другой просмотр должен освободить
эту камеру перед запуском. Пока IMX519 не зарегистрирована, программа
завершается с сообщением `IMX519 not found`.

Демка не управляет автофокусом, усилением или экспозицией. Сильный фильтр
может сглаживать детали и оставлять шлейфы. Обработка не заменяет
калибровку сенсора/объектива и tuning ISP. Пересвет и оптические
отражения она не исправляет. Исходник — [MIT](../LICENSE.MIT).
