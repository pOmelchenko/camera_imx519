# Печатные мишени для камер

Исходники получены от владельца 2026-09-26 из каталогов `Mira600dpi` и
`AFTestChart300dpi` в Downloads. Исходные `.doc` и `.png` скопированы без
изменений; их хеши и хеши готовых PDF записаны в [SHA256SUMS](SHA256SUMS).
На мишенях указан `www.fotosav.ru`; страницы с описанием
[плоской миры](https://www.fotosav.ru/articles/faq/lens/lensvs.aspx) и
[мишени автофокуса](https://www.fotosav.ru/articles/faq/back_focus/back_focus_testing.aspx)
приведены как справочные. Точные URL, с которых были скачаны четыре исходных
файла, не установлены. Метаданные DOC указывают автора Victor Savushkin:
`Mira600dpi.doc` сохранён 2011-02-07, `AFTestChart.doc` — 2011-08-25.

Пошаговая [инструкция по печати и установке](INSTRUCTIONS.md) сохранена
локально на основе обеих статей Fotosav.

Все три PDF имеют одну страницу A4 (297 × 210 мм), альбомную ориентацию.
Печатайте с параметром **«Фактический размер / Actual Size», 100%**.
Отключите `Fit to Page`, подгонку под поля и масштабирование драйвера
принтера. У плоской миры внизу есть контрольная линейка длиной 100 мм:
измерьте её на отпечатке, прежде чем сравнивать снимки. Готовый PDF миры
сохранён из ранее подготовленного файла без повторного экспорта. PDF шкалы
строится из исходного PNG скриптом [make-af-pdf.py](make-af-pdf.py) без
растеризации или изменения числа пикселей:

```sh
python3 hardware/camera/test-charts/make-af-pdf.py
```

Новая миллиметровая версия сохраняет компоновку исходной мишени, но
перерисовывает шкалу, частые полосы, центральную площадку, оба опорных
лепестка и общий внешний контур векторной геометрией. Печатные пояснения
вверху убраны; происхождение шаблона записано здесь. Короткие риски и
полосы идут с шагом `√2 мм` на бумаге, то есть 1 мм по глубине
при **точном** наклоне 45°. Числа подписаны через 5 мм глубины, а по нижнему
полю PDF проведена отдельная контрольная линия 100 мм. Для пересборки:

```sh
python3 hardware/camera/test-charts/make-af-mm-pdf.py
```

Более мелкая шкала сама по себе не гарантирует точности автофокуса до 1 мм:
проверяйте масштаб отпечатка, угол установки и повторяемость наведения.

Для плоской миры нужна ровная матовая поверхность; при необходимости
закрепите отпечаток на жёстком основании. Для проверки AF наведитесь на
центральную мишень, расположенную перпендикулярно оптической оси; шкала
должна идти под углом 45°. Не оценивайте равномерность резкости по наклонной
шкале: для этого служит плоская мира.
