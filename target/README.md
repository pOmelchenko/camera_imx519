# Целевые платформы

Каждая платформа хранит подключение этой камеры, требования к драйверу,
код, патчи, команды и результаты в собственном каталоге.

- [SBC](sbc/README.md): Linux-платы с CSI и своей подсистемой захвата.
- [Микроконтроллеры](mcu/README.md): SDK, инициализация сенсора, ISP/DMA и буферы.

Статус указан в README конкретной платы. Наличие каталога не подтверждает
поддержку. Общие свойства камеры и распиновка находятся в
[справочнике](../docs/README.md); ОС и базовая подготовка хоста описываются
в документации платы. Зависимости `vendor/`, сборки `build/`, захваты и логи
остаются локальными. Проверенные инструкции публикуются в `docs/guides`.
