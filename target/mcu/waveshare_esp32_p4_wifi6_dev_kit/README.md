# IMX519 Autofocus на Waveshare ESP32-P4

**Статус: возможный маршрут; драйвер, сборка и захват не проверены.**
Для ESP32-P4-WIFI6-DEV-KIT нет готового пути этой камеры в пакете.

## Необходимые работы

1. Зафиксировать ревизию платы и её CSI connector по
   [документации Waveshare](https://www.waveshare.com/wiki/ESP32-P4-WIFI6-DEV-KIT).
   Проверить питание, уровни, число линий и ориентацию шлейфа по
   [распиновке камеры](../../../docs/reference/pinout.md).
2. Закрепить ESP-IDF и
   [esp-video-components](https://github.com/espressif/esp-video-components).
   Проверить наличие подходящего сенсорного драйвера в выбранном release;
   при отсутствии реализовать управление и регистры режима для этого модуля.
3. Согласовать сенсор с CSI/ISP, RAW-форматом, тактированием, DMA/PSRAM
   и буферами. Linux-драйверы и Pi overlays здесь не применяются.
4. Получить один кадр и проверить цвет/экспозицию; затем измерить устойчивый
   поток, потери, память и запись отдельно от передачи по USB/Ethernet.
5. Подключить драйвер привода объектива, затем отдельно реализовать
   и проверить autofocus. Зафиксировать фокус для калибровки.

Код, патчи и команды этой связки размещаются здесь вместе с
[результатом проверки](../../../docs/development/README.md).
Заявленные режимы сенсора не устанавливают пропускную способность MCU.
